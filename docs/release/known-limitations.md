# Known Release Limitations

- User screenshots and Playwright traces are no longer served from public static paths. Run artifacts use a five-minute signed ticket bound to user, project, run and artifact kind; access rechecks current membership. A ticket is a temporary bearer capability, so avoid persisting/sharing it and do not log it. Static Playwright Trace Viewer application assets remain public and contain no user trace bytes.
- Current `npm audit --omit=dev` reports 3 Moderate advisories (0 High), all through `@fastify/static@10.1.3` → `glob@13.0.7` → `minimatch@10.2.6`. npm recommends `@fastify/static@10.1.10`, which brings `content-disposition@3` declaring Node >=22; the current supported runtime baseline is Node 20. Do not force this upgrade until the Node baseline is deliberately moved or a compatible upstream fix is available. The earlier Low dev-only esbuild advisory is fixed by `tsx@4.23.15` / `esbuild@0.28.2`; full audit now reports only the same 3 Moderate findings. `mcp-server` production audit reports 0 vulnerabilities. Prisma remains 6.19.3; a scoped `@prisma/config` override to `deepmerge-ts@8.0.2` removed the previous High finding and passed isolated migrations, seed and backend tests.
- Private/VPC HTTP Request destinations remain blocked unless an administrator configures the server-side exact-host allowlist. User-controlled project settings cannot relax this policy.
- A killed worker may repeat external side effects from an already-started browser, HTTP or SQL step even though SuiteRun/TestRun creation and coordinator transitions are designed to be idempotent. Exactly-once behavior for arbitrary external systems is not guaranteed.
- Some legacy project tabs do not fully preserve their URL through refresh/back navigation; see the E2E characterization notes. This Phase 8 pass does not silently redefine those product behaviors.
- Full endpoint-by-endpoint RBAC/IDOR coverage, provider-backed PostgreSQL/MySQL integration tests, broad UI E2E and complete restart/schedule regression remain outside the Phase 8.1 evidence. Three provider-dependent backend tests were skipped in the last isolated unit suite.
- The frontend production bundle still emits a Vite warning for the 1,622 kB initial JavaScript chunk. This is not a security blocker but remains a performance limitation.
