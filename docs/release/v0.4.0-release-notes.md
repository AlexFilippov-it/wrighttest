# WrightTest v0.4.0

> Published on 2026-11-09. This file is the repository copy of the v0.4.0 release notes.

WrightTest v0.4.0 expands the existing low-code Playwright workflow with API and database checks, richer variables, sequential Suites, and local MCP integration.

## Highlights

- **HTTP/API testing:** configure HTTP requests in regular Checks, assert response status, headers, timing, JSON and text, and capture typed response values for later steps.
- **SQL checks:** use PostgreSQL and MySQL connections with bounded SQL steps, bound parameters, assertions, capture, and encrypted connection credentials.
- **Typed variables and data-driven Checks:** combine run inputs, test data, environment and project values; capture and reuse values while preserving types and secret metadata.
- **Sequential Suite Runs:** order Checks and pass explicitly mapped outputs to later Checks within an isolated Suite Run.
- **MCP server:** connect a local stdio MCP client to WrightTest using a personal API token. The server provides 32 tools across project/check/suite/run workflows, project variables, safe database-connection metadata, and browser exploration.
- **Editor and diagnostics:** improve Check editing, responsive Run Results, step-level HTTP/SQL/Browser diagnostics, and navigation to failed steps.
- **Security and reliability:** improve authorization, secret handling, artifact access, outbound request checks, and worker/Suite recovery. Security Gate 1 remains PARTIAL; see Known limitations.
- **Windows container checkout fix:** thanks to **hendricktlv** for contributing `.gitattributes` rule `*.sh text eol=lf`, which keeps shell scripts on LF line endings when Git checks out the repository on Windows with `core.autocrlf=true`.

## Validation

- CI passed for PR #9 and for the merged `main` commit.
- Release Validation passed on the merged `main` commit, including Compose builds, E2E smoke, integration scenarios, API testing, worker restart, and Mixed Check.
- The release checks and their scope are recorded in [the regression matrix](./regression-matrix.md) and [the release readiness audit](./release-readiness-audit.md).

## Known limitations

- Security Gate 1 is **PARTIAL**. The confirmed Check-import authorization defect is fixed and regression-tested, but a complete runtime matrix across all routes and MCP tools was not run.
- Three Moderate production dependency advisories remain; no High advisories were reported in the dated audit. See [known limitations](./known-limitations.md) for scope and disposition.
- Docker Hub `0.4.0` and `latest` tags are published for backend, frontend and noVNC. The previous `0.3.0` tags remain available.
